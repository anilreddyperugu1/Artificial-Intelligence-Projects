# 🤖 Personal AI Portfolio Assistant

Personal AI Portfolio Assistant is an AI-powered conversational system designed to help users to explore my professional profile through natural language interactions. Instead of navigating a traditional portfolio website, users can ask questions about my projects, technical skills, certifications, education, and experience, receiving context-aware responses generated by a Large Language Model (LLM).

The project transforms a static portfolio into an interactive AI experience, enabling seamless exploration of technical achievements and professional background.

# 🚀 Project Overview

Traditional portfolios require recruiters to manually navigate through multiple sections to understand a candidate's technical capabilities and achievements.

The **Personal AI Portfolio Assistant** transforms a static portfolio into an interactive AI experience by allowing recruiters to ask questions in natural language and receive context-aware responses generated by Google's Gemini LLM.

# 🎯 Problem Statement

No problem statement. Just making recruiters life easier with this project😂

The challenge is to provide a faster and more engaging way for recruiters to understand:

- Technical Skills

This project addresses that challenge through an AI-powered conversational assistant.
